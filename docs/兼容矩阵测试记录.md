Gerber DFM 必须保留的回归点：

- 正常导出无 `Gerber Export` issue。
- 缺层、空层、ZIP 缺项为 error。
- 缺 drill 为 error，缺 map 为 warning。
- fallback 输出目录为 warning。
- 完整性 issue 在三档 profile 下 severity 一致。
- `0.135mm` trace aperture 在三档 profile 下颜色不同。
- `0.500mm` slot width 在三档 profile 下颜色不同。
- 带板名前缀文件名，例如 `video-CuTop.gbr`、`video-EdgeCuts.gbr`，可被完整性和扫描逻辑识别。
- Gerber 一行多命令、大小写命令、命令内部空格、旧式 `G54Dnn` aperture select 能被解析。
- `%FS` 坐标格式、前/后导零抑制、G90/G91、G70/G71 能影响坐标和单位。
- G02/G03 圆弧、G36/G37 region、G74/G75 象限模式、%LPD/%LPC 极性和 clear mask 能生成正确 primitive。
- `%SR` step repeat 支持大小写和内部空格，reset 后不再影响后续图形。
- 标准圆/矩形/椭圆/多边形 aperture、aperture hole 和常见 macro primitive 能生成 flash/clear mask。
- Gerber spacing、pad size、PTH annular ring、holes on SMD pads、drill-to-copper、copper-to-board-edge 结果携带 `segment`、`point` 或 `bbox`，能归一化为详情窗口定位高亮坐标。
- Pad Size 直接使用 pad 外形较短一边，Long/Short 分界为长宽比 1.2，不扣除 Excellon 钻孔。
- Drill Hole Spacing 必须检查相同网络 via；同网 PTH 不得套用 Different Net PTH Spacing。
- Drill-to-Copper 的 PTH/Via 子项只接收真实 trace，pad flash 和 zone/region 不得触发；NPTH-to-Copper 覆盖全部铜层的 trace、pad 和铺铜，每个物理孔仅保留一条 `Drl` 层全局最小结果。
- 正常 SMD pad 阻焊开窗不得进入 Missing SMask Openings；阻焊桥、阻焊盖线和阻焊覆盖多个网络分别进入 `Solder Mask Analysis` 三个稳定子项。
- `video` 的 `+5V` PTH 焊盘通过内层 `VCC_layer` 已填充 zone 的热焊盘/孔环连接时，不得报告 `Signal Integrity / Trace Mssing`；判断必须使用实际填充铜形状，不能只检查 pad 中心点。
- 进度条必须显示当前工作内容；点击停止后不得继续剩余检查，也不得覆盖最近一次完整缓存。
- `video` 四层 Gerber 回归不得恢复铜间距、孔到铜、阻焊或信号完整性的全量二次方交叉遍历；空间索引只能排除数学上不可能触发规则的候选，所有红色/黄色违规必须完整保留，禁止按 10/20/50/2000 条静默截断或只保留全局最差违规。
- 详情窗口切换不同问题条目时，选择过程只记录缩放范围，图层和标记处理完成后只执行一次最终缩放。
- 缩放用焦点框不能复用已删除的 SWIG 图形对象；GUI 中延迟短暂保留后自动删除，避免 KiCad 异步视图还没完成时焦点框已消失。
- KiCad 8.0+ 使用原生 `pcbnew.FocusOnItem()`；KiCad 6.0/7.0 没有该 API 时只保留选中、高亮和临时目标标记，不再发送菜单、快捷键、鼠标或系统按键模拟缩放。
- 定位后 PCB 上只保留可编辑目标标记和原始对象选中/加亮状态；track 类对象保留精确线段和外围目标框，便于快速找到问题位置。
- 坐标命中不到原始 PCB 对象时，详情窗口必须按 `sx/sy/ex/ey`、`result` 或 `bbox_nm` 回退绘制目标位置，不能静默无高亮。
- `ChildFrameSetting.layer_conversion()` 必须使用 KiCad 常量和安全层名读取，不能固定枚举无效 layer id，避免 KiCad 6.0-8.0 assertion 中断详情定位。
- `tools/verify_detail_locate_kicad_versions.py` 必须保留真实 DFM 单条结果和 `DfmChildFrame.analysis_process()` 连续切换测试，防止只首条缩放、后续条目不缩放、目标标记缺失或缩放框泄漏回归。
