# 功能总览

## 插件入口

插件入口位于 `plugin.py`，实现 `pcbnew.ActionPlugin`：

- 名称：`HQ DFM`
- 分类：`Manufacturing`
- 描述：`One click analysis design hidden dangers.`
- 图标：`kicad_dfm/picture/icon.png`
- 运行动作：调用 `kicad_dfm._main._main()`

`_main.py` 委托 `kicad_dfm.main.main()` 启动插件，后者通过 `SINGLE_PLUGIN.show_existing()` 保证主窗口只打开一个实例。

## 用户主流程

1. 在 KiCad PCB Editor 点击 `HQ DFM`。
2. 主窗口读取当前 PCB，并记录进入插件时的可见层和可见元素。
3. 在规则组单选按钮中选择制造规则，默认 `Standard`。
4. 点击“快速 DFM 检查”执行基于当前 PCB 对象的 Native 分析。
5. 在准备生产文件前点击“综合 DFM 检查”；插件依次运行 Native、导出并扫描 Gerber/Excellon、完成 UUID/网络语义补充，再合并结果。
6. 分析期间进度条同步显示当前检查类目或处理阶段；需要提前结束时点击 `Stop Analysis`，取消信号会终止后续检查且不会把不完整结果写入缓存。
7. 主窗口刷新制造规则摘要；快速结果只含 `kicad_native` 来源，综合结果会合并 Native 和 Gerber 观测，交付完整性问题在发现时自动弹窗提示。
8. 点击异常项打开详情窗口。
9. 在详情窗口选择问题后，插件定位、高亮或标记对应 PCB 对象；Gerber/Drill 文件结果使用坐标绘制临时高亮。
10. 如详情窗口隐藏了部分层，可在主窗口点击 `Reset Layers` 显示全部 PCB 层和可见元素。

分析成功后，插件会把可持久化的完整结果保存到 PCB 旁的 `HQDMF/analysis-cache-v23/`。再次打开同一 PCB 的 DFM 窗口时，如果 PCB 内容、规则组、界面语言和相关 Gerber/Drill 输入都没有变化，会在后台自动恢复摘要和详情，不再重复运行分析。启动恢复优先使用最新有效结果：综合分析缓存不可用时会继续回退到 Gerber 或 KiCad Native 缓存，因此单独运行快速检查后也能在下次打开时恢复。手动重新执行分析会原子写入新缓存；停止或失败的分析不会覆盖已有完整结果。缓存版本随规则/算法契约升级而失效；PCB 目录不可写时使用系统临时目录下按 PCB 路径隔离的回退缓存。单个缓存上限为 128 MiB，并有 100 万树节点的预检上限；超过任一限制时跳过该综合缓存，但本次界面结果仍有效，且 Native 缓存仍可用于下次恢复。

## 快速与综合结果差异

| 项目 | 快速 DFM 检查 | 综合 DFM 检查 |
| --- | --- | --- |
| 运行模式 | `kicad_native` | `kicad_native` + `gerber_strict` + `gerber_enriched`，最终发布 `combined` |
| 数据来源 | 当前内存中的 KiCad PCB 对象 | 保存后的 PCB、实际 Gerber/Excellon 输出和 Native 结果 |
| 设计语义 | UUID、网络、footprint、NetTie、层跨等信息完整 | Gerber 先按制造几何检查，再尽量回映 UUID/网络语义 |
| 文件交付检查 | 不检查 | 检查缺层、空文件、钻孔/map、ZIP 和铜层数量 |
| 合并行为 | 直接展示 Native 结果 | 按稳定 finding key 去重；同一问题保留来源观测，enriched 是 Gerber 最终判定来源 |
| 推荐使用时机 | 布局布线过程中频繁运行 | 下单、归档或交付制造文件前运行 |

综合结果不是两个问题数量的简单相加：同一物理问题可能合并为一项；strict Gerber 疑似项在 UUID、网络和 NetTie 补充后也可能被确认合法并抑制。反过来，绘制圆整、阻焊扩展、实际钻孔工具或输出文件异常只会出现在综合检查中。

## 主窗口能力

- 规则组选择：`Basic`、`Standard`、`Advanced`。
- 规则管理：查看和编辑当前规则组阈值，说明图使用语言无关底图和本地化位置标注。
- 快速 DFM 检查：离线检查当前 PCB 对象，不导出制造文件。
- 综合 DFM 检查：先运行 Native，再导出 `HQDMF/Gerber_<PCB文件名>` 和 `HQDMF/Gerber_<PCB文件名>.zip`，本地扫描 Gerber/Drill 文件并合并，不上传。
- 分析进度与停止：进度条显示当前检查内容，`Stop Analysis` 会设置协作式取消信号并停止剩余步骤。
- 结果摘要：显示检查项、数值和颜色状态。
- 华秋 DFM 提示：结果表格下方提供可点击的 DFM 链接；中文界面打开 `https://dfm.hqpcb.com`，英文界面打开 `https://www.nextpcb.com/dfm`。
- Gerber 文件完整性提示：综合检查发现制造文件交付问题时自动弹窗，无固定主界面行。
- 重置可见层：显示全部 PCB 层和可见元素。

## 摘要检查项

| 项目 | 来源 | 当前行为 |
| --- | --- | --- |
| Layer Count | KiCad 本地 | 显示铜层数 |
| Dimensions | KiCad 本地 | 显示板框尺寸 |
| Signal Integrity | KiCad/Gerber 本地/远端兼容 | KiCad 本地检查断线、锐角、孤立铜、悬空线端和未连接过孔；锐角结果以两根相连 Trace 为一组并同时定位、高亮；Gerber 本地对所有规则组检查断网、外层铜锐角、孤立铜，并利用 X2 网络属性检查悬空走线和未连接过孔；远端结果仍可兼容展示 |
| Smallest Trace Width | KiCad/Gerber 本地 | 遍历走线宽度；Gerber 铜层 draw aperture 宽度会并入 |
| Smallest Trace Spacing | KiCad/Gerber 本地/远端兼容 | 分别检查同层走线—走线、走线—焊盘和焊盘—焊盘间距，并按当前规则组的独立子项阈值着色 |
| SMD Spacing | KiCad/Gerber 本地/远端兼容 | 独立检查非 BGA 的 SMD 焊盘间距，默认阈值为 6/8/10 mil；综合分析用 KiCad UUID 和局部几何关系识别 NetTie，不做全板网络等价 |
| Pad size | Gerber/KiCad 本地 | 直接使用焊盘外形较短一边；长宽比大于 1.2 归入 Long Pads，不扣除钻孔尺寸 |
| Hole Size | Gerber/KiCad/远端兼容 | Excellon tool 的最小/最大直径、PTH 专用孔径、板厚/孔径（孔厚径比），以及 slot 最小/最大宽度、外形总长和长宽比会并入；Gerber 不含板厚时从 PCB 获取 |
| RingHole | 本地已实现 | 检查过孔和 PTH 孔环；Gerber X2 `ViaPad` 与普通 PTH pad 分别归类 |
| Drill Hole Spacing | Gerber/KiCad/远端兼容 | 计算孔边到孔边间距；相同网络过孔仍按 Same Net Via Spacing 检查，同网 PTH 不套用 Different Net PTH Spacing |
| Drill to Copper | Gerber/KiCad/远端兼容 | PTH/Via 子项只检查孔边到走线，不包含焊盘和铺铜；NPTH-to-Copper 内部检查全部铜层的走线、焊盘和铺铜，但每个物理孔仅输出一条全局最小结果，显示层固定为 Drl |
| Copper-to-Board Edge | Gerber/KiCad/远端兼容 | 可解析铜层直线到 EdgeCuts 距离、EdgeCuts 开口会并入 |
| Hole-to-Board Edge | Gerber/KiCad 本地 | 检查插件孔、Via、螺丝孔和普通 NPTH 的孔壁到真实 Edge.Cuts 最近距离；圆孔、旋转长圆槽均按实际孔形计算 |
| Special Drill Holes | Gerber/KiCad/远端兼容 | 仅包含有明确直角证据的正/长方形孔和孔与板框相交形成的半孔；圆角长圆槽不归入正/长方形孔，Excellon 文件结构异常归入 Gerber Export |
| Holes on SMD Pads | KiCad 本地/远端兼容 | 仅以 SMD 焊盘为目标，检查 Via/BGA Via、NPTH、PTH 与其实际铜形状的重叠 |
| Missing SMask Openings | KiCad/Gerber 本地/远端兼容 | 检查 SMD pad 阻焊开窗属性及外层铜区到同侧 F/B.Mask 开窗的对应关系，避免正常 pad 开窗误报 |
| Solder Mask Analysis | KiCad/Gerber 本地 | 检查阻焊桥、具有预期 pad 网络的开窗到异网走线间距，以及单个开窗覆盖多个网络 |
| Drill Hole Density | KiCad 本地/远端兼容 | 统计实际钻孔数并除以板框有效面积；中文显示为 `x.xx万/m²` |
| Surface Finish Area | KiCad 本地/远端兼容 | 统计两面阻焊开窗内的焊盘及未盖油过孔铜面积，显示其占单面板有效面积的百分比 |
| Test Point Count | KiCad 本地/远端兼容 | 统计有网络且可从外层接触的焊盘和未盖油过孔数量，直接显示整数 |
| Gerber Export（后台结果） | Gerber 本地 | 记录输出目录、缺文件、空文件、ZIP、铜层数量、钻孔/map、板框文件等交付完整性问题；有问题时自动弹窗 |

Gerber/Excellon 是制造几何，不一定保留 PCB 的全部设计语义。盲埋孔层跨、板厚、BGA footprint 类型、螺丝孔用途等信息缺失时，Gerber 分析不会猜测；这些子项以快速检查中的 Native 结果为准。纯制造文件中的非镀孔先归入普通 NPTH，综合分析成功回映 PCB 后再按 mounting/screw footprint 语义改归螺丝孔。

## 规则和颜色

规则阈值格式为：

```text
报警阈值, 预警阈值, 上限/辅助参数
```

规则优先级：

1. 当前主窗口选中的规则组。
2. 分析结果中携带的规则。
3. `kicad_dfm/core/rule_catalog.py` 内置默认规则。

颜色含义：

- `red`：严重超限。
- `gold`：预警范围。
- `black`：符合规则。
- 空颜色：无异常或不适用。

## 详情窗口

详情窗口支持：

- 按层过滤问题。
- 按问题子类型过滤问题。
- 全部/只看异常切换。
- 首个、上一个、下一个、最后一个导航。
- 显示与当前问题匹配的语言无关底图，并按当前语言在配置坐标处绘制说明标注。
- “分析类别”和“分析子项”显示文本均随插件语言切换，并在类别后显示当前所选图层中的结果数量；切换图层或“显示所有/警报项”后会重新统计。内部仍使用稳定规则键进行筛选和定位；右侧结果表不重复显示已选类别，只列出序号、严重级别、数值和图层。
- 详情窗口在筛选区显示当前子项的实际规则值，并按当前 mm/mil/inch 单位转换；下方规则说明区左侧显示检查含义、风险阈值和建议值，右侧显示对应规则示意图。54 个分析子项的说明均支持中英文切换。
- 点击问题后定位并高亮 PCB 对象。
- Gerber/Drill 文件结果若包含坐标，则绘制临时线段高亮并聚焦；缺文件、ZIP 等文件级问题只展示详情，不隐藏全部图层。
- 大结果集只选择前 200 个对象、标记前 20 个对象，避免 KiCad 卡顿。
- 文件级 Gerber Export 问题没有 PCB 对象坐标，综合检查结束时的文件完整性弹窗只显示问题文本。

## I18N 和图片

- gettext 翻译资源位于 `kicad_dfm/language/locale`。
- 简体中文目录：`zh_CN/LC_MESSAGES/kicad_hqdfm_plugin.po/.mo`。
- 新增 UI 文案后运行 `python tools/i18n_compile.py`。
- 检查项说明图位于 `kicad_dfm/picture/diagram`，同一图示只维护一张无文字底图。
- 图片说明文案由 `kicad_dfm/child_frame/diagram_catalog.py` 中的 gettext key 提供，新增语言只需补充翻译文本。
